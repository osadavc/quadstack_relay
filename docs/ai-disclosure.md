# AI tool disclosure

Relay uses no AI at runtime. Its planner follows fixed rules and produces the same plan for the same inputs.

We used **Claude Code** (Anthropic, Claude Opus models) minimally during the Hackathon for coding help, tests and documentation. We made the product and engineering decisions, reviewed the code and tested the final system.

**OpenAI Codex** assisted with the operating-constraint audit, frozen-order support, depot-specific order closure, outdated-draft publishing checks, and their regression tests and documentation.

We used only the permitted General Data files. No data was invented, and nothing was copied from other teams or published solutions.
